[![Build APK & LaTeX](https://github.com/ImArthz/Flutter/actions/workflows/build_and_release.yml/badge.svg)](https://github.com/ImArthz/Flutter/actions/workflows/build_and_release.yml)

> **Institution:** CEFET-MG Divinópolis  
> **Professor:** Michel Pires da Silva  

This project is a practical and detailed study on Advanced Data Structures, covering the implementation, asymptotic analysis, and benchmarking of the following trees:
1. Splay Tree
2. Treap
3. Trie
4. Patricia Tree (Radix Tree)
5. KD-Tree

The repository contains three main parts organized in this folder:
- 📱 `app_flutter/`: Interactive Flutter application that renders the trees and allows step-by-step operations with a built-in simulator.
- 📈 `scripts_benchmark/`: Python scripts used to generate stress tests, evaluating time and memory complexities.
- 📄 `artigo_academico/`: Complete scientific paper written in LaTeX with plotted benchmark charts.

## 🛠️ How to Run Locally

### Flutter App
```bash
cd app_flutter
flutter pub get
flutter run
```

### Benchmarks (Python)
```bash
cd scripts_benchmark
pip install matplotlib seaborn pandas
python benchmark.py
python plot_benchmark.py
```
