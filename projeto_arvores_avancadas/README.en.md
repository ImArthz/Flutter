## About the Project

This project is a practical and detailed study on **Advanced Data Structures**, covering the implementation, asymptotic analysis, and benchmarking of the following trees:

| # | Structure | Type |
|---|-----------|------|
| 1 | **Splay Tree** | Self-Adjusting Binary Tree |
| 2 | **Treap** | Probabilistic Binary Tree |
| 3 | **Trie** | Prefix Tree |
| 4 | **Patricia Tree** | Radix Tree (Compressed Trie) |
| 5 | **KD-Tree** | 2D Spatial Search Tree |

The repository contains three main parts:
- **`app_flutter/`** - Interactive Flutter application that renders the trees and allows step-by-step operations with an automatic simulator.
- **`scripts_benchmark/`** - Python scripts used to generate stress tests, evaluating time and memory complexities.
- **`artigo_academico/`** - Complete scientific paper written in LaTeX with plotted benchmark charts.

## How to Install and Run

### Android
1. Download the **APK** file above.
2. On your phone, open the file and allow installation from unknown sources.
3. The app will be installed and ready to use.

### Windows
1. Download the **arvores_app_windows.zip** file above.
2. **Extract** the ZIP contents (right-click > Extract All).
3. Inside the extracted folder, run **`arvores_app.exe`**.
4. **Important:** Do not move the `.exe` outside its folder. It needs to stay alongside the `data/` folder and `flutter_windows.dll` to work.

### Linux
1. Download the **arvores_app_linux.tar.gz** file above.
2. Extract it with:
   ```bash
   tar -xzf arvores_app_linux.tar.gz
   ```
3. Give execution permission and run:
   ```bash
   chmod +x arvores_app
   ./arvores_app
   ```
4. **Dependencies:** Requires GTK3 libraries installed. On most Ubuntu/Debian distros:
   ```bash
   sudo apt-get install libgtk-3-0
   ```

## How to Build Locally

### Flutter App
```bash
cd app_flutter
flutter pub get
flutter run              # Run on connected device
flutter build apk        # Generate Android APK
flutter build windows    # Generate Windows EXE
flutter build linux      # Generate Linux app
```

### Benchmarks (Python)
```bash
cd scripts_benchmark
pip install matplotlib seaborn pandas
python benchmark.py
python plot_benchmark.py
```
